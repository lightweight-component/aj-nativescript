# aj-nativescript Java library

This is a Java library project that can be opened directly from Android Studio.

## Build

From this directory, run:

```powershell
.\gradlew.bat :aj-nativescript:jar
```

The resulting artifact is written to:

```text
aj-nativescript/build/libs/aj-nativescript-1.0.0-SNAPSHOT.jar
```

The library's Java package is `com.ajaxjs.nativescript`.
